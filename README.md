# 📊 Loan Applications & Funding Trends Analysis

## 📌 Project Overview

The **Loan Applications & Funding Trends Analysis** project is an exploratory data analysis project focused on understanding loan application patterns, funding trends, repayment performance, loan quality, and borrower characteristics.

The objective of this project is to transform raw financial loan data into meaningful insights using Python, statistical analysis, and data visualization techniques.

The analysis covers key business metrics such as:

- Total Loan Applications
- Month-to-Date (MTD) Loan Applications
- Total Funded Amount
- Total Amount Received
- Good Loans
- Bad Loans
- Monthly Loan Trends
- Regional Analysis
- Loan Term Analysis
- Employee Length Analysis
- Loan Purpose Analysis
- Home Ownership Analysis

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze the overall volume of loan applications.
2. Calculate Month-to-Date (MTD) loan applications.
3. Analyze the total amount funded.
4. Analyze the total amount received from borrowers.
5. Compare Good Loans and Bad Loans.
6. Identify monthly trends in loan applications.
7. Analyze monthly funding and amount received trends.
8. Understand loan activity across different regions.
9. Analyze loan distribution based on loan terms.
10. Study loan applications based on employee length.
11. Identify the most common loan purposes.
12. Analyze loan applications based on home ownership.
13. Generate meaningful business insights from the data.
